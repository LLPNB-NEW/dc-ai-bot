隐私政策

适用应用：Discord 机器人「示例机器人」（应用 ID 150000000000000001）· 生效日期：2026-10-25

本政策说明这个 Discord 机器人在处理你的数据时做了什么、没做什么。它由个人自托管，运行在 Cloudflare Workers 上，不是商业化服务。

1. 我们处理哪些数据

当你在这个机器人所在的服务器里使用斜杠命令时，它会处理：

  • 你的 Discord 用户 ID、用户名，以及所在服务器 / 频道的 ID 与名称；
  • 你主动发给机器人的文本内容（例如 /chat 的提示词）；
  • 机器人自己产生的回复内容，以及消息时间戳。

机器人不会读取你在 Discord 里的其他消息，也不会获取你的邮箱、手机号、支付信息或好友列表。

2. 数据用来做什么

  • 把你的输入和最近的对话上下文发给大模型，生成回复；
  • 按频道保存最近若干轮对话（默认为最近 20 轮，超出后自动裁剪最旧的内容），以便多轮对话连贯。

3. 数据存在哪里、保存多久

会话记录存储在 Cloudflare D1（由 Cloudflare 运营的托管数据库），按「服务器 + 频道」维度保留最近若干轮，默认 20 轮，超出即自动删除。你可以随时在频道里执行 /reset 清空该频道的全部记录。

4. 第三方共享

为了生成回复，你发送的内容与最近的对话上下文会被发送给这个机器人所配置的大模型供应商（例如 OpenAI、Anthropic、Google，或它们的中转 / 兼容服务）。这些数据的后续处理受该供应商自己的隐私政策约束。除此之外，机器人不向任何第三方共享或出售你的数据，页面中也不包含广告或行为追踪脚本。

5. API 密钥

大模型 API 密钥由管理员在后台录入，使用 AES-256-GCM 加密后存储；后台页面对密钥只显示末位提示（如 …cdef），任何接口都不会回显明文或密文。密钥不会写入日志，也不会出现在发往 Discord 的响应里。

6. 安全

全站通过 HTTPS 访问，Discord 交互请求会校验 Ed25519 签名后才被接受；敏感配置以 Cloudflare Secrets 保存。但请注意：没有任何互联网服务能承诺绝对安全。

7. 你的选择

  • 清空自己的会话：在频道内执行 /reset；
  • 要求删除或询问数据处理：通过 Discord 联系 example_user；
  • 不使用时可不调用该机器人，服务器管理员也可以随时把它移出服务器。

8. 年龄限制

本机器人不面向 13 岁以下用户（即 Discord 的最低使用年龄）。

9. 政策变更

如果数据处理方式发生变化，本页面会同步更新并修改上方的生效日期。继续使用即表示接受更新后的政策。
